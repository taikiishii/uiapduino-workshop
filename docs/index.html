マイコンと UIAPduino ってなに？

スマホの中にも入っている「マイコン」の話と、290円のボード UIAPduino の紹介。
2🧰

Arduino IDE をじゅんびしよう

プログラムを作る道具（Arduino IDE）を入れて、UIAPduino を使えるようにしよう。
3💡

はじめてのLチカ

基板のLEDをチカチカさせよう。書き込みのしかたと、プログラムの形をおぼえる。
🔌 基本編 LED・スイッチ・つまみ　＜ここまでで半日コース＞
1🔴
🚧 写真まち

ブレッドボードにLEDをつなごう

ブレッドボードのしくみをおぼえて、自分でつないだLEDを光らせよう。
2🔘
🚧 写真まち

スイッチでLEDをつけよう

ボタンを押したときだけLEDが光るようにしよう。デジタル入力の回。
3🌗

LEDの明るさを変えよう

ついている・消えているだけでなく、とちゅうの明るさにしてみよう。
4🎛️
🚧 写真まち

つまみで明るさを変えよう

可変抵抗（つまみ）を回すと、LEDの明るさがぬるっと変わるようにしよう。
5🔔

音を鳴らそう

ブザーをつないで音を出そう。音の高さは「1秒間に何回ふるえるか」で決まる。
🔁 制御編 くりかえしと条件でプログラムを組み立てる　＜ここまでで1日コース＞
1📦

変数をつかおう

数をしまっておく「箱」＝変数。名前をつけると、プログラムがぐっと読みやすくなる。
2🔁

くりかえし（for）

同じことを何回もくりかえす書き方。LEDをじわっと光らせよう。
3🔀

もし〜なら（if / else）

条件によって動きを変えよう。「暗くなったら光る」が作れるようになる。
4🧩

配列と関数でまとめよう

たくさんのLEDをひとまとめに。同じ処理は関数にまとめてすっきりさせよう。
🚀 発展編 センサーで感じて、モーターで動かす
1🔦
🚧 写真まち

光センサーで暗くなったら光る

明るさをはかるセンサーをつないで、自動で点灯するライトを作ろう。
2🌡️
🚧 写真まち

温度をはかろう

温度センサーで気温をはかって、暑くなったら知らせるようにしよう。
3📏
🚧 写真まち

ものとの距離をはかろう

超音波センサーで距離をはかろう。音がはね返る時間から距離がわかる。
4🦾
🚧 写真まち

サーボモーターを動かそう

角度を指定してピタッと止まるモーター。ロボットの腕やしっぽに使えるよ。
5⚙️
🚧 写真まち

モータードライバでDCモーター

モーターをぐるぐる回そう。正転・逆転・スピード調節までできるよ。
🧩 拡張編 ライブラリを使って、部品をふやす
1📟

文字を表示しよう（LCD）

16文字×2行の画面に、文字や数を出そう。はじめてライブラリを使うよ。
🛠 作品編 自分だけの作品を、構想から発表まで　＜複数日コース＞
1💡

なにを作るか決めよう

アイデアの出し方と、大きすぎる構想の切り方。1文で言えたら決まり。
2📐

設計図をかこう

見た目・つなぎ方・動きの順番。3枚かくと、作るときに迷わない。
3🛒

材料と道具をあつめよう

電子部品と工作材料の両方がいる。買うものは早めに決めよう。
4🔋

電源をどうするか

パソコンにつながなくても動く作品にしよう。えらび方と、ぜったいやってはいけないこと。
5🦴

骨格をつくろう

動くものは土台が9割。よくある失敗と、材料・くっつけ方のえらび方。
6🔧

くみたてよう

少しずつ足して確かめる。まとめて作ると、どこが悪いか分からなくなる。
7🎤

発表しよう

なにを作ったか・どう動くか・くふうしたところ。動かして見せるのがいちばん。
8🚀

つぎの一歩

UIAPduino でできること・できないこと。もっと作りたくなったら、どの道具をえらぶ？
📎 付録 部品・ピン配置・こまったとき・はんだ付け
1🧾
🚧 写真まち

部品リストと回路の見方

使う部品の名前と、抵抗のカラーコード・配線図の読み方。
2🆘

こまったときは

書きこめない・光らない・動かない。よくあるつまずきと、その直し方。
3📌

ピン配置早見表

どのピンが何に使えるか（アナログ入力・PWM・I2C・SPI）の公式ピン配置図と早見表。
4🔥
🚧 写真まち

ピンヘッダをはんだ付けしよう

自分でボードを買った人むけ。はんだ付けの道具・やり方・注意点。
5📚
🚧 写真まち

ライブラリを追加しよう

ライブラリの入れかたと、入らない・動かないときの考え方。拡張編と自由制作で使う。
6🧰
🚧 写真まち

ライブラリを作ろう

自分でライブラリを作って、LCD をメモリ半分で動かそう。中身まで知りたい人へ。
7🎨

抵抗のカラーコードの読み方

抵抗についている色の帯の意味。1kΩ と 10kΩ を自分で見分けられるようになろう。
8📋

メンター用 早見表

当日メンターが手元に置く1枚。使うピン・つまずきどころ・時間の目安。
9📄

配布用 1枚紙

当日くばる紙。教材のQRコードと、書きこみの手順だけを1ページに。
10⚠

実機とコアの落とし穴

公式ピン配置図どおりに使えない点と、コアの不具合。教材を作る人・改造する人むけ（技術者向け）。
