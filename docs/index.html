基板のLEDをチカチカさせよう。書き込みのしかたと、プログラムの形をおぼえる。

🚧 写真まち

スイッチでLEDをつけよう

ボタンを押したときだけLEDが光るようにしよう。デジタル入力の回。

🚧 写真まち

LEDの明るさを変えよう

ついている・消えているだけでなく、とちゅうの明るさにしてみよう。

🚧 写真まち

つまみで明るさを変えよう

可変抵抗（つまみ）を回すと、LEDの明るさがぬるっと変わるようにしよう。
5🔔
🚧 写真まち

音を鳴らそう

ブザーをつないで音を出そう。音の高さは「1秒間に何回ふるえるか」で決まる。
🔁 制御編 くりかえしと条件でプログラムを組み立てる　＜ここまでで1日コース＞
1📦

変数をつかおう

数をしまっておく「箱」＝変数。名前をつけると、プログラムがぐっと読みやすくなる。
2🔁

くりかえし（for）

同じことを何回もくりかえす書き方。LEDをじわっと光らせよう。
3🔀

もし〜なら（if / else）

条件によって動きを変えよう。「暗くなったら光る」が作れるようになる。
4🧩
🚧 写真まち

配列と関数でまとめよう

たくさんのLEDをひとまとめに。同じ処理は関数にまとめてすっきりさせよう。
🚀 発展編 センサーで感じて、モーターで動かす
1🔦
🚧 写真まち

光センサーで暗くなったら光る

明るさをはかるセンサーをつないで、自動で点灯するライトを作ろう。
2🌡️
🚧 写真まち

温度をはかろう

温度センサーで気温をはかって、暑くなったら知らせるようにしよう。
3📏
🚧 写真まち

ものとの距離をはかろう

超音波センサーで距離をはかろう。音がはね返る時間から距離がわかる。
4🦾
🚧 写真まち

サーボモーターを動かそう

角度を指定してピタッと止まるモーター。ロボットの腕やしっぽに使えるよ。
5⚙️
🚧 写真まち

モータードライバでDCモーター

モーターをぐるぐる回そう。正転・逆転・スピード調節までできるよ。
6🏆
🚧 写真まち

オリジナル作品をつくろう

ここまでの部品を組み合わせて、自分だけの作品を作って発表しよう。

部品リストと回路の見方

使う部品の名前と、抵抗のカラーコード・配線図の読み方。

こまったときは

書きこめない・光らない・動かない。よくあるつまずきと、その直し方。
3📌

ピン配置早見表

ピンヘッダをはんだ付けしよう

自分でボードを買った人むけ。はんだ付けの道具・やり方・注意点。

🚧 写真まち

ライブラリを追加しよう

本編では使わない、少し高度な話。自由制作で部品を増やしたい人へ。
