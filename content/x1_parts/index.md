# ① 部品リストと回路の見方

部品と配線図のよみかた

*UIAPduino 体験ワークショップ*

---

# かならず使うもの
どの章でも使う、基本のセットだよ。

- **UIAPduino Pro Micro CH32V003 V1.4** … 290円
- **USB Type-C ケーブル** … 短めで、データ通信ができるもの
- **ブレッドボード** … はんだ付けなしでつなげる板
- **ジャンパーワイヤ** … オス−オス。20本くらいあると安心

> ⚠ USBケーブルは「充電専用」だと書きこめない。データ通信対応のものを。

---

# 光る・音が出るもの
出力（動かす）がわの部品だよ。

- **LED** … 赤・黄がおすすめ（青や白は暗くなりがち）
- **抵抗 330Ω** … LED 1個につき1本
- **圧電ブザー（受動型）** … 音の高さを変えられるもの

> ⚠ ブザーには「能動型」もある。そちらは**音の高さが変えられない**ので、
> 買うときは「**受動**」「パッシブ」と書いてあるものを選ぼう。

---

# 感じるもの（センサー）
入力がわの部品。作りたいものに合わせて選ぼう。

- **タクトスイッチ** … 押しボタン
- **可変抵抗 10kΩ** … つまみ
- **CdS（光センサー）暗抵抗 1MΩ** ＋ **抵抗 10kΩ**
- **温度センサー MCP9700-E/TO**（秋月 109692）
- **超音波センサー HC-SR04** … グループで共用してもOK

---

# 動かすもの
大きな力を出す部品。**別の電源**が必要になるよ。

- **サーボモーター**（SG90 など）
- **DCモーター** ＋ **モータードライバ**
  （DRV8835 モジュール／秋月電子 109848）
- **電池ボックス**（単3×4本＝6V など）

> ⚠ モーターやサーボをUSBだけで動かすと、ボードが再起動することがある。

---

# 抵抗の読み方

:::

抵抗には色の帯がついていて、それが数字を表しているよ。

- **330Ω** … だいだい・だいだい・茶
- **10kΩ** … 茶・黒・だいだい

> 帯の色の意味：黒0・茶1・赤2・だいだい3・黄4・緑5・青6・むらさき7・灰8・白9

> ⚠ 見分けにくいときは、**テスターで測る**か、袋のままにしておこう。

:::

> 📷 330Ω と 10kΩ の抵抗を大きく並べて写した写真

---

# ブレッドボードの読み方

:::

穴のつながりを覚えておくのが大事だよ。

- **たて5つの穴**が中でつながっている
- みぞをまたぐと**べつのグループ**
- 横の長い列（＋と−）は**横一列**

> ⚠ 同じたてならびなら、離れて見えてもつながっているよ。

:::

> 📷 ブレッドボードの穴のつながりを色分けした図

---

# 配線図の見方
このテキストでは、こんなふうに書くよ。

- **3V3 ── CdS ── A2 ── 10kΩ ── GND**
- 左から順に、**線でつなぐ順番**を表している
- `──` の間にあるものが、そこに入る部品

> 実物とくらべながら、1つずつ指でたどると分かりやすいよ。

---

# 買うときのめやす
自分で買いそろえるときの参考に。

- ボードとケーブル … 約1,000円
- ブレッドボード・ジャンパー・LED・抵抗 … 約1,000円
- センサー類（選んで） … 1つ100〜500円
- サーボ／モーター類 … 1つ400〜800円

> 秋月電子・スイッチサイエンス・マルツなどで買えるよ。
> ボードの買い方は、もくじの下の**参考リンク**を見てね。
