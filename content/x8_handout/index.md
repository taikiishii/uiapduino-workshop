# UIAPduino 体験ワークショップ

:::

プログラムを入れるときは、**この順番**だよ。

1. USBケーブルを**抜く**
2. **RESETを押しながら**さす → すぐはなす
3. **→（書き込み）**を押す
4. `Image written.` が出たら **RESETをもう1回**

> ⚠ 4番を忘れると、動きださないよ。

:::
