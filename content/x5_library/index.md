# ⑤ ライブラリを追加しよう

もっといろいろな部品を使いたい人へ

*UIAPduino 体験ワークショップ*

---

# このワークショップでは使わない
**このテキストの23章は、ライブラリを1つも使わずに作ってある**よ。

- サーボも、超音波センサーも、自分で書いた
- 追加インストールなしで、全部の章ができる

> ここは「自由制作で、もっと変わった部品を使いたい」人のためのページだよ。

---

# ライブラリってなに？

:::

**だれかが作ってくれた、便利な部品セット**のこと。

- むずかしい処理が、あらかじめ書いてある
- `#include` と書くだけで、その機能が使えるようになる
- 世界中の人が作って、無料で公開している

> 「毎回ゼロから作らなくていいように」というしくみだよ。

:::

> 📷 ライブラリマネージャの画面

---

# 入れかた

:::

Arduino IDE の**ライブラリマネージャ**から入れるよ。

1. 左のアイコンから **本のマーク**をクリック
2. 使いたい部品の名前で検索する
3. **インストール** をクリック

> 板のマークが「ボード」、本のマークが「ライブラリ」だよ。

:::

> 📷 ライブラリマネージャで検索している画面

# ⚠ 入らないことがある
このボードは、プログラムを入れる場所が **16KB しかない**。

- Lチカだけで、すでに **42%** を使っている
- 残りは **9KB ほど**
- 大きなライブラリは、**そもそも入らない**

> 「メモリが足りません」というエラーが出たら、それが原因だよ。

---

# ⚠ 動かないことがある
入っても動かない場合があるんだ。

- ライブラリの多くは **AVR**（べつの種類のマイコン）向けに作られている
- このボードは **RISC-V** という、ちがう種類のマイコン
- ピンやタイマーの使い方がちがうと、動かない

> 実際、このワークショップでも `pulseIn` という命令が使えなかった。
> だから**自分で書いた**んだ（e3 の距離センサー）。

---

# 入らない・動かないときは
あきらめる前に、この順で考えてみよう。

1. **もっと軽いライブラリ**をさがす（"lite" "minimal" など）
2. **自分で書けないか**考える（`digitalWrite` と `delayMicroseconds` で十分なことも多い）
3. 部品を**べつのもの**に変える

> このテキストの e3・e4 は、まさに **2番目のやり方**で作られている。
> 中身が見えるぶん、**自分で調整できる**という良さもあるよ。

---

# 自分で書くという選択
ライブラリは便利だけど、中で何をしているかは見えない。

- 自分で書くと、**しくみが分かる**
- 数字を変えて**自分の部品に合わせられる**
- うまくいかないとき、**どこが悪いか探せる**

> サーボの `600` と `2400`、距離の `- 2`。
> どれも「自分で書いたから調整できた」数字なんだ。

> 💪 ライブラリを使うか、自分で書くか。
> どちらが合っているかを考えられるようになったら、もう立派な作り手だよ。
