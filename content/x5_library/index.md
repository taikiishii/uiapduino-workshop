# ⑤ ライブラリを追加しよう

もっといろいろな部品を使いたい人へ

*UIAPduino 体験ワークショップ*

---

# 使うのは拡張編だけ
**このワークショップ資料は、発展編まではライブラリを1つも使わずに作ってある**よ。

- サーボも、超音波センサーも、自分で書いた
- ライブラリを入れるのは、**拡張編**の LCD だけ

> ここは、拡張編でライブラリを入れる人と、
> 「自由制作で、もっと変わった部品を使いたい」人のためのページだよ。

---

# ライブラリってなに？

:::

**だれかが作ってくれた、便利な部品セット**のこと。

- むずかしい処理が、あらかじめ書いてある
- `#include` と書くだけで、その機能が使えるようになる
- 世界中の人が作って、無料で公開している

> 「毎回ゼロから作らなくていいように」というしくみだよ。

:::

# 入れかた

:::

Arduino IDE の**ライブラリマネージャ**から入れるよ。

1. 左のアイコンから **本のマーク**をクリック
2. 使いたい部品の名前で検索する
3. **インストール** をクリック

> 板のマークが「ボード」、本のマークが「ライブラリ」だよ。

:::

> 📷 ライブラリマネージャで検索している画面

# ⚠ 入らないことがある
このボードは、プログラムを入れる場所が **16KB しかない**。

- Lチカだけで、すでに **42%** を使っている
- 残りは **9KB ほど**
- 大きなライブラリは、**そもそも入らない**

> 「メモリが足りません」というエラーが出たら、それが原因だよ。

---

# ⚠ 動かないことがある
入っても動かない場合があるんだ。

- ライブラリの多くは **AVR**（べつの種類のマイコン）向けに作られている
- このボードは **RISC-V** という、ちがう種類のマイコン
- ピンやタイマーの使い方がちがうと、動かない

> 実際、このワークショップ資料でも `pulseIn` という命令が使えなかった。
> だから**自分で書いた**んだ（e3 の距離センサー）。

---

# 入らない・動かないときは
あきらめる前に、この順で考えてみよう。

1. **もっと軽いライブラリ**をさがす（"lite" "minimal" など）
2. **自分で書けないか**考える（`digitalWrite` と `delayMicroseconds` で十分なことも多い）
3. 部品を**べつのもの**に変える

> このワークショップ資料の e3・e4 は、まさに **2番目のやり方**で作られている。
> 中身が見えるぶん、**自分で調整できる**という良さもあるよ。

---

# 自分で書くという選択
ライブラリは便利だけど、中で何をしているかは見えない。

- 自分で書くと、**しくみが分かる**
- 数字を変えて**自分の部品に合わせられる**
- うまくいかないとき、**どこが悪いか探せる**

> サーボの `600` と `2400`、距離の `- 2`。
> どれも「自分で書いたから調整できた」数字なんだ。

---

# 例：LCD をもっと軽く
拡張編①の LCD は、「数をかぞえる」だけでメモリを **88%** 使う。

- いちばん大きいのは LCD のライブラリではなく、**I2C のしくみ（Wire）**
- I2C を**自分で書く**と、同じことが **45%** で済む
- Lチカ（42%）と、ほとんど変わらない

> ここからは、中身まで知りたい人向け。**書き写すだけでも動く**よ。

---

# 自分のライブラリを作ろう

:::

ライブラリは、**ただのファイル**。自分でも作れるよ。

1. 右上の「…」から「**新しいタブ**」
2. 名前を **LcdMini.h** にする
3. つぎの4ページのコードを書き写す
4. スケッチの1行目に `#include "LcdMini.h"`

> `" "` は「同じフォルダのファイル」、`< >` は「入れたライブラリ」の意味だよ。

:::

> 📷 新しいタブで LcdMini.h を作った画面

# ① 線を上げ下げする

:::

I2C は、**2本の線**を上げ下げして合図を送るよ。

- **SDA** … 送る中身（0 か 1）
- **SCL** … 「いま読んで」の合図
- 上げる＝**はなす**。基板の抵抗で HIGH になる

> HIGH を自分で出さないので、線がぶつかっても**こわれない**よ。

:::

```cpp `LcdMini.h` ① 線を上げ下げする
// LcdMini.h … LCD 1602（I2C）を Wire なしで動かす
const int SDA_PIN = 3, SCL_PIN = 4;  // SDA＝3番・SCL＝4番
const byte LCD_ADDR = 0x3F;          // LCD のアドレス

void sen(int pin, bool up) {         // 線を上げる（はなす）か下げる
  pinMode(pin, up ? INPUT : OUTPUT); // はなすと、基板の抵抗で HIGH
  if (!up) digitalWrite(pin, LOW);
}

void i2cByte(byte b) {               // 1バイトを 1ビットずつ送る
  for (int i = 0; i < 8; i++) {
    sen(SDA_PIN, b & 0x80);          // いちばん上のビット
    sen(SCL_PIN, true);              // SCL を上げ下げすると
    sen(SCL_PIN, false);             //   1ビット読んでもらえる
    b = b << 1;
  }
  sen(SDA_PIN, true);                // 返事の1ビット（読まない）
  sen(SCL_PIN, true); sen(SCL_PIN, false);
}
```

# ② 1バイトとどける

:::

LCD の基板に 1バイトとどける手順だよ。

1. **はじめの合図**
2. **あて先**（アドレス）
3. **中身**
4. **おわりの合図**

> LCD は、1バイトを **4ビットずつ2回**に分けて受けとるよ。

:::

```cpp `LcdMini.h` ② 1バイトとどける
void i2cSend(byte v) {               // LCD の基板に 1バイトとどける
  sen(SDA_PIN, true);  sen(SCL_PIN, true);
  sen(SDA_PIN, false); sen(SCL_PIN, false);  // はじめの合図
  i2cByte(LCD_ADDR << 1);                    // あて先
  i2cByte(v);                                // 中身
  sen(SDA_PIN, false); sen(SCL_PIN, true);
  sen(SDA_PIN, true);                        // おわりの合図
}

void lcdHalf(byte v) {               // 4ビットぶん送る
  i2cSend(v | 0x0C);                 // 0x08＝明かり・0x04＝読んで！
  i2cSend((v & ~0x04) | 0x08);
}

void lcdSend(byte v, byte rs) {      // 1バイトを 2回に分けて送る
  lcdHalf((v & 0xF0) | rs);          // 上の4ビット
  lcdHalf((v << 4) | rs);            // 下の4ビット
}
```

# ③ LCD に命令する

:::

LCD には**命令**と**文字**を送るよ。

- `lcdCmd` … 命令（消す・場所を決める など）
- `lcdInit` … 決まった手順で使いはじめる
- `lcdAt` … 書く場所。2行目は `0x40` から

> 命令の番号は、チップの説明書で決まっているよ。

:::

```cpp `LcdMini.h` ③ LCD に命令する
void lcdCmd(byte c) {                // 命令を送る
  lcdSend(c, 0);
  delay(2);
}

void lcdInit() {                     // LCD を使いはじめる
  sen(SDA_PIN, true); sen(SCL_PIN, true);
  delay(50);
  lcdHalf(0x30); delay(5);           // 決まった手順で
  lcdHalf(0x30); delay(1);           //   目をさまさせて
  lcdHalf(0x30); lcdHalf(0x20);      // 4ビットで話すと決める
  lcdCmd(0x28); lcdCmd(0x0C);        // 2行・画面オン
  lcdCmd(0x01); lcdCmd(0x06);        // 消す・右へ進む
}

void lcdAt(byte col, byte row) {     // 何文字目・何行目から書くか
  lcdCmd(0x80 | (col + row * 0x40)); // 2行目は 0x40 から
}
```

---

# ④ 文字と数を出す

:::

- `lcdStr` … 文字を 1文字ずつ送る
- `lcdNum` … 数を 1けたずつ文字にして送る

> 数は **10でわったあまり**で、下の桁から取り出す。
> だから、出すときは**逆の順**にしているよ。

:::

```cpp `LcdMini.h` ④ 文字と数を出す
void lcdStr(const char *s) {         // 文字を出す
  while (*s) lcdSend(*s++, 1);       // 1文字ずつ送る
}

void lcdNum(int n) {                 // 数を出す
  char b[7];
  int i = 0;
  if (n < 0) { lcdSend('-', 1); n = -n; }
  do {
    b[i++] = '0' + n % 10;           // 下の桁から取り出して
    n = n / 10;
  } while (n);
  while (i) lcdSend(b[--i], 1);      // 上の桁から出す
}
```

# 使ってみよう

:::

つなぎかたは**拡張編①と同じ**だよ。

- **GND**→GND・**VCC**→5V
- **SDA**→**3番**・**SCL**→**4番**

書きこんで、メモリが **45%** で済むことを確かめよう。

> ⚠ 返事を読んでいないので、アドレスがちがってもエラーにならない。
> 出ないときは `LCD_ADDR` を `0x27` にしてみよう。

:::

```cpp `x5_lcdmini` 自作ライブラリで数をかぞえる
#include "LcdMini.h"

int n = 0;

void setup() {
  lcdInit();
  lcdStr("count");
}

void loop() {
  lcdAt(0, 1);
  lcdNum(n);
  n = n + 1;
  delay(1000);
}
```
