# ③ はじめてのLチカ

はじめてのプログラムを書きこもう

*UIAPduino 体験ワークショップ*

---

# なにをするの？

:::

基板についている**オレンジのLED**を、チカチカ光らせるよ。

これは **Lチカ**（LEDをチカチカさせる）といって、
世界中のマイコン使いが**いちばん最初にやること**なんだ。

- プログラムの**形**をおぼえる
- ボードへの**書きこみ方**をおぼえる
- 光る速さを**自分で変えてみる**

> ここができれば、あとはぜんぶ応用だよ。いっしょにやっていこう！

:::

> 📷 オレンジのLEDが光っている基板の写真（暗めの背景だと光がきれいに写る）

---

# プログラムの形をおぼえよう

:::

Arduino のプログラムは、**2つの部屋**でできているよ。

- `setup()` … **さいしょに1回だけ**やること
  （じゅんび体操みたいなもの）
- `loop()` … **ずっとくりかえし**やること
  （ぐるぐる回りつづける）

> 電源を入れると、まず `setup()` を1回。
> そのあと `loop()` の中身を、**電源を切るまでずーっとくりかえす**んだ。

:::

```cpp プログラムの形
void setup() {
  // さいしょに1回だけ
}

void loop() {
  // ずっとくりかえし
}
```

---

# 手順①：新しいスケッチを作る

:::

Arduino では、プログラムのことを **スケッチ** とよぶよ。

1. Arduino IDE の **ファイル** → **新規スケッチ**
2. まっさらな画面が出てくる
3. `setup()` と `loop()` が最初から書いてある

> 中に書いてある英語の文（`// put your setup code here` など）は
> **メモ書き**だから、消してしまってOKだよ。

:::

> 📷 新規スケッチを開いた直後の画面

---

# 手順②：プログラムを入力しよう

:::

下のプログラムを入力しよう。右上の **📋 コピー** を使ってもいいよ。

1. さいしょに書いてあるものを**ぜんぶ消す**
2. 下のプログラムを貼りつける（`Ctrl` + `V`）
3. `Ctrl` + `T` を押すと、**字下げがきれいにそろう**

> ⚠ `;`（セミコロン）と `{ }`（かっこ）を忘れやすいよ。コピーを使うと安心。

:::

```cpp はじめてのLチカ
const int LED = 2;          // 基板のオレンジLED

void setup() {
  pinMode(LED, OUTPUT);     // このピンは「出力」に使うよ
}

void loop() {
  digitalWrite(LED, HIGH);  // 光らせる
  delay(500);               // 0.5秒まつ
  digitalWrite(LED, LOW);   // 消す
  delay(500);               // 0.5秒まつ
}
```

---

# 手順③：書きこみモードにする ★大事

:::

ここが **UIAPduino でいちばん大事なところ**。順番をまちがえると書きこめないよ。

1. USBケーブルを **いったん抜く**
2. **RESETボタンを押しながら**、USBケーブルを挿す
3. 挿したら、**すぐ RESET をはなす**
4. **青いLED**がついていることをたしかめる

> ⚠ 「押しながら挿す」が大事。**押す → 挿す → はなす** の順番だよ。

> うまくいかないときは、もう一度 1 からやりなおせばOK。何回でもやり直せるよ。

:::

> 📷 RESETボタンを指で押さえながらUSBを挿している手元の写真（矢印で①押す ②挿す ③はなす）

---

# 手順④：ボードに書きこもう

:::

1. Arduino IDE の左上の **→（右向きの矢印）** をクリック
2. 下の黒いところに、文字がたくさん流れる
3. **`Image written.`** と出たら、書きこみ成功！

> はじめての書きこみは、少し時間がかかることがあるよ。あわてずに待とう。

> ⚠ エラーが出たら、手順③の**書きこみモード**からやりなおしてみよう。

:::

> 📷 書き込みボタン（→）を赤く囲んだ画面と、「Image written.」が出た黒い画面

---

# 手順⑤：RESETを押して動かそう

:::

書きこんだだけでは、まだ動きださないよ。

1. 基板の **RESETボタンを1回押す**
2. オレンジのLEDが **チカチカ** しはじめたら大成功！ 🎉

> `Image written.` のあとに **RESETをもう1回**。これで自分のプログラムが動きだすよ。

:::

> 📷 チカチカしているようす（2枚：点いているところ・消えているところ）

---

# プログラムを読んでみよう

:::

さっき書いたプログラムの意味を、1行ずつ見てみよう。

- `const int LED = 2;` … 2番ピンに **LED という名前**をつける
- `pinMode(LED, OUTPUT);` … このピンを**出力（電気を出す）**に使う、と決める
- `digitalWrite(LED, HIGH);` … 電気を出す → **光る**
- `digitalWrite(LED, LOW);` … 電気を止める → **消える**
- `delay(500);` … **500ミリ秒（0.5秒）**まつ

> `//` から右は**メモ書き**。プログラムの動きには関係しないから、
> 日本語で好きなことを書いていいよ。

:::

> 📷 コードに①〜⑤の番号をふった図（Greenshotで注釈）

---

# ⚠ このボードの、ちょっと変わったところ

:::

Arduino の本やネットの記事には、よく **シリアルモニタ** というものが出てくる。
プログラムの中の数字をパソコンの画面に表示するしくみだよ。

でも **UIAPduino では、シリアルモニタは使えない**んだ。

- `Serial.print` を書いても、画面には出てこない
- そのかわり、このワークショップでは
  **LEDの明るさや点滅の回数**で数字を見えるようにするよ

> こまったときのたしかめ方は「**LEDを光らせてみる**」。これがこのボードの合言葉。

:::

> 📷 このスライドは文字だけでもOK（必要なら「使えません」のイラスト）

---

# 💪 やってみよう

:::

プログラムの数字を変えて、動きがどう変わるか見てみよう。

1. `delay(500)` の **500 を 100** にして書きこむ → どうなる？
2. **500 を 2000** にして書きこむ → どうなる？
3. 光っている時間と消えている時間を、**べつべつの数**にしてみよう

> 💪 **SOS** を光で送ってみよう。
> トン・トン・トン（短く3回）→ ツー・ツー・ツー（長く3回）→ トン・トン・トン

> 変えるたびに、**手順③の書きこみモードから**やりなおすのを忘れずに。

:::

> 📷 数字を変えた例（delay の部分だけを赤く囲む）
