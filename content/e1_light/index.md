# ① 光センサーで暗くなったら光る

くらさを感じて自動で光る

*UIAPduino 体験ワークショップ*

---

# なにをするの？

:::

いよいよ**センサー**の登場だよ。

- **CdS**（光センサー）で明るさをはかる
- 暗くなったら、自動でLEDが光る
- 使うのは `analogRead` と `if`。**どちらももう習った**

> つまみをセンサーに置きかえるだけ。c3 の続きなんだ。

:::

> 📷 手でセンサーをおおうとLEDが光る写真（2枚：明るいとき・おおったとき）

---

# CdS ってなに？

**明るさによって、電気の通しやすさが変わる**部品だよ。

- 明るい … 電気を通しやすい（抵抗が小さい）
- 暗い … 電気を通しにくい（抵抗が大きい）

向きはないので、どちら向きでもOK。

> 表面のうねうねした模様が、光を受けるところ。指でさわらないようにね。

---

# つまみと組にして使う

:::

CdS だけでは電圧にならない。**10kΩ のつまみ**と組にするよ。

1. **5V** ── CdS ── **A2** ── つまみ ── **GND**
2. まん中（CdS と つまみ のあいだ）が **A2**
3. つまみは**まん中の足と、片はしの足**の2本だけ使う

> あとで**さかいめを決める**のに、このつまみを回すよ。

:::

![5V ── CdS ── A2 ── つまみ ── GND。配線はこれで最後まで変えない](image/index/bb_cds.png)

---

# 明るさで点滅が変わる

:::

`analogRead` は 0〜1023。**4 でわった 0〜255** を
そのまま**待ち時間（ミリ秒）**にするよ。

1. つまみを**時計回りに**回しきる（＝10kΩ）
2. 書きこんで、手を**丸めて**かぶせる

> 明るいと 205、おおうと 37 ミリ秒くらい。
> 指1本だとすきまから光が入るよ。

:::

```cpp `e1_check` 明るさで点滅が変わる
const int CDS = A2;
const int LED = 5;

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  int t = analogRead(CDS) / 4;   // 明るいほど長い
  digitalWrite(LED, HIGH); delay(t);
  digitalWrite(LED, LOW);  delay(t);
}
```

---

# 数で読んでみよう

:::

`analogRead` は **0〜1023** の数を返す。
**100 でわる**と **0〜10** になるので、その回数だけ光らせるよ。

1. 右のプログラムを書きこむ
2. LEDが**点滅する回数**を数える
3. 回数 × 100 が、だいたいの値

> 明るいと **8回**（≒800）、おおうと **1回**（≒100）くらい。

:::

```cpp `e1_kazu` 値を数で読む
const int CDS = A2;
const int LED = 5;

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  int n = analogRead(CDS) / 100;
  for (int i = 0; i < n; i++) {
    digitalWrite(LED, HIGH); delay(200);
    digitalWrite(LED, LOW);  delay(300);
  }
  delay(2000);        // ひと休み
}
```

# 自動ライトにしよう

:::

さかいめは部屋ごとに変わる。**つまみで合わせよう**。

1. 右のプログラムを書きこむ
2. 明るいまま、**反時計回り**にゆっくり回す
3. LEDが光ったら**少しもどす**（ぎりぎり消える位置）
4. 手でおおうと、**パッと光る**

> `500` は動かさない。**つまみのほうで合わせる**んだ。

:::

```cpp `e1_light` 暗くなったら光る
const int CDS = A2;
const int LED = 5;

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  if (analogRead(CDS) < 500) {
    digitalWrite(LED, HIGH);   // 暗い → 光る
  } else {
    digitalWrite(LED, LOW);
  }
  delay(50);
}
```

# 💪 やってみよう

しきい値と動きを工夫してみよう。

1. 明るさに応じて、**だんだん明るくなる**ようにする（`analogWrite`）
2. 暗くなったら**音も鳴る**ようにする（b5 のブザー）
3. `else if` で3段階に分ける（明るい・ふつう・暗い）

> 💪 街灯のように「**暗くなってすぐには消えない**」ようにできるかな。
> 明るくなっても数秒待ってから消す、という工夫だよ。
