# ① ブレッドボードにLEDをつなごう

自分でつないだLEDを光らせる

*UIAPduino 体験ワークショップ*

---

# なにをするの？

:::

- **ブレッドボード**の穴のつながり方をおぼえる
- LEDには**向き**がある（足の長いほうが＋）
- **抵抗**を入れないとLEDがこわれる。**330Ω** を使うよ

:::
