# ⑤ 音を鳴らそう

*UIAPduino 体験ワークショップ*

---

# なにをするの？

:::

- `tone()` で音を鳴らし、`noTone()` で止める
- 数字が**大きいほど高い音**（1秒間にふるえる回数＝周波数）
- ⚠ 音とLEDのフェードを同時に使うときは、LED を D5・D10・A0〜A3 につなぐ

:::
