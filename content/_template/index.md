# 手順①：つないでみよう

:::

1. **USBケーブルを抜く**
2. ブレッドボードに部品をさす
3. ジャンパーワイヤーでボードとつなぐ

> ヒントや注意はこの吹き出しで。

> ⚠ 配線を変えるときは、かならずUSBを抜いてからにしよう。

:::

# 手順②：プログラムを書きこもう

:::

1. 下のプログラムを入力する（右上の「📋 コピー」も使えるよ）
2. **RESETを押しながら**USBを挿す → すぐ離す
3. 「→（書き込み）」を押す
4. `Image written.` が出たら **RESETをもう1回押す**

> 💪 数字を変えると、どう変わるかためしてみよう。

:::

```cpp キャプションはここに書く
const int LED = 5;

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  digitalWrite(LED, HIGH);
  delay(500);
  digitalWrite(LED, LOW);
  delay(500);
}
```
