# ④ サーボモーターを動かそう

角度を指定して動かす

*UIAPduino 体験ワークショップ*

---

# なにをするの？

:::

ここからは「**動かす**」の番だよ。

- サーボモーターは **角度を指定して**その位置で止まる
- ロボットの腕、しっぽ、ハンドルなどに使える
- ライブラリは**使わない**。しくみがそのままコードになる

> ふつうのモーターはぐるぐる回るだけ。サーボは**止められる**のがちがいだよ。

:::

> 📷 サーボが0度・90度・180度を向いている写真（3枚）

---

# パルスで角度が決まる

:::

サーボは、**信号の長さ**で角度を決めるという、ちょっと変わった部品だよ。

- **20ミリ秒ごと**に、短い信号（パルス）を送る
- パルスが**短い**と 0度、**長い**と 180度
- 1回送っただけでは動かない。**送り続ける**のがコツ

> 信号の長さで伝えるなんて、モールス信号みたいだね。

:::

> 📷 パルスの長さと角度の関係を描いた図

# つなごう

:::

サーボには線が3本あるよ。**USBを抜いてから**つなごう。

1. **茶または黒** … **GND**
2. **赤** … **5V**
3. **黄または橙** … **5番ピン**

> ⚠ 線の色と順番に注意。逆につなぐとサーボが壊れることがあるよ。
> わからないときは、かならずメンターと確かめてね。

:::

> 📷 サーボの3本の線と配線を写した写真

---

# ⚠ 電気をたくさん使う

:::

サーボは、LEDとくらべて**とても多くの電気**を使うよ。

動かした瞬間に**ボードが再起動する**（LEDが消えてやり直しになる）ことがある。
それは電気が足りていないサインだよ。

そのときは、**乾電池などからサーボに電気を送る**。
そして **GND だけをボードとつなぐ**（これを忘れると動かない）。

:::

# プログラムを書きこもう

:::

パルスを作る部分と、角度を指定する部分に分けるよ。

1. 右のプログラムを書きこむ
2. 0度 → 90度 → 180度 とくりかえす
3. `600` と `2400` で動く範囲が変わる

> `for` で50回くりかえすのは「**1秒間、送り続ける**」ため。

:::

```cpp サーボを動かす
const int SERVO = 5;

void servoPulse(int us) {        // パルスを1回おくる
  digitalWrite(SERVO, HIGH);
  delayMicroseconds(us);         // 600〜2400 で角度がきまる
  digitalWrite(SERVO, LOW);
  delay(20);                     // 20msごと ＝ 1秒に50回
}

void muku(int kakudo) {          // その角度をむく
  int us = map(kakudo, 0, 180, 600, 2400);
  for (int i = 0; i < 50; i++) servoPulse(us);
}
```

# 自分のサーボに合わせよう

:::

サーボは**個体差が大きい**。同じ数字でも動く範囲がちがうよ。

- 範囲がせまい → `600` を小さく、`2400` を大きく
- 端で「**ジー**」とうなる → 範囲を**せまく**する

> ⚠ うなったまま放っておくとサーボが傷む。すぐ調整しよう。

:::

# 💪 やってみよう

角度の指定を工夫してみよう。

1. `muku(45)` や `muku(135)` を試して、とちゅうの角度に止める
2. `for` を使って、0度から180度まで**ゆっくり**動かす
3. b2 のスイッチで、押すたびに角度が変わるようにする

> 💪 e3 の距離センサーと組み合わせて、
> 「**近づくとしっぽがふれる**」しかけを作ってみよう。

> 💪 つまみ（b4）で角度を決められるようにもできるよ。
