# ③ LEDの明るさを変えよう

0 と 1 のあいだをつくる

*UIAPduino 体験ワークショップ*

---

# なにをするの？

:::

LEDを**とちゅうの明るさ**にしてみるよ。

- `analogWrite` で明るさを **0〜255** で指定する
- 0 が消灯、255 がいちばん明るい
- 配線は前の章のまま。プログラムだけ変える

> うすく光らせたり、じわっと明るくしたりできるようになるよ。

:::

> 📷 同じLEDを3段階の明るさで撮り比べた写真

---

# ほんとうは点滅している

:::

じつは、とちゅうの明るさは**うそ**なんだ。

- **ものすごく速く点滅**している（1秒に1000回）
- 点いている時間が長いほど**明るく見える**
- このしくみを **PWM** という

> 💪 光っているLEDを見ながら**手をすばやくふって**みよう。
> 点々に見えたら、点滅している証拠だよ。

:::

> 📷 LEDを振って撮った写真（点々に写る・長時間露光）

---

# ⚠ おまじないが1行いる

:::

このボードで `analogWrite` を使うときは、`setup()` に**この1行**を入れる。

- 「明るさを **0〜255** で指定する」という宣言
- これが無いと、`255` を指定してもほとんど光らない

> ⚠ 忘れると「暗いまま」になる。うまくいかないときは、まずこの行を確認。

:::
```cpp
analogWriteResolution(8);
```
> 📷 この行がある場合と無い場合の明るさを比べた写真

---

# ⚠ 使えるピンが決まっている

:::

明るさを変えられるのは、**この5本だけ**だよ。

- **`0` `2` `5` `6` `12`**

ほかのピンで `analogWrite` を書いても、明るさは変わらない。
ピンによっては**まったく光らない**こともある。

> 前の章から **5番** を使っているのは、このためだったんだ。

:::

![明るさを変えられるのは、みどりの5本だけ](image/index/pins_pwm.png)

> くわしくは付録の「**ピン配置早見表**」を見てね。

---

# プログラムを書きこもう

:::

3段階の明るさを、じゅんばんに切りかえるよ。

1. 右のプログラムを書きこむ
2. 暗い → ちょっと明るい → いちばん明るい とくりかえす
3. 数字を変えて、好きな明るさをさがしてみよう

> `64` は 255 の約4分の1。数字を大きくするほど明るくなるよ。

:::

```cpp 明るさを3段階で変える
const int LED = 5;          // PWMが使えるピン

void setup() {
  pinMode(LED, OUTPUT);
  analogWriteResolution(8); // 明るさは0〜255
}

void loop() {
  analogWrite(LED, 0);    delay(500);   // 消灯
  analogWrite(LED, 64);   delay(500);   // ちょっと
  analogWrite(LED, 255);  delay(500);   // いちばん明るい
}
```

# 💪 やってみよう

明るさの数字をいろいろ試してみよう。

1. **10 / 30 / 100 / 200** をためして、見え方をくらべる
2. 一番くらい「光っているのが分かる」数字をさがす
3. 2つのLEDを**ちがう明るさ**で同時に光らせる

> 💪 数字を少しずつ大きくして、**じわっと明るくなる**ようにしたい。
> でも `analogWrite` を256回書くのは大変……

> それを1行で書く方法が、次の**制御編**にあるよ。
