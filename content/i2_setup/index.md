# ② Arduino IDE をじゅんびしよう

プログラムを作る道具をそろえる

*UIAPduino 体験ワークショップ*

---

# なにをするの？

:::

プログラムを書くための道具、**Arduino IDE（アイディーイー）** をじゅんびするよ。

やることは3つ。

1. Arduino IDE を**インストール**する
2. UIAPduino を**使えるようにする**（設定を1つ追加）
3. 使うボードを**えらぶ**

> ⚠ このじゅんびは**さいしょの1回だけ**。次からはすぐプログラムを書けるよ。

:::

> 📷 Arduino IDE を立ち上げた最初の画面

---

# 手順①：Arduino IDE を入れる

:::

1. ブラウザで `https://www.arduino.cc/en/software` をひらく
2. 自分のパソコンに合うものをえらぶ（Windows なら **Windows** ）
3. ダウンロードしてインストールする

> 教室のパソコンには**もう入っている**ことが多いよ。デスクトップにアイコンがないか探してみよう。

> ⚠ 「寄付をおねがいします」という画面が出たら、**JUST DOWNLOAD** を押せば進めるよ。

:::

> 📷 Arduino 公式サイトのダウンロードページ（「Windows」のボタンを赤く囲む）

---

# 手順②：設定画面をひらく

:::

Arduino IDE は、そのままでは UIAPduino を知らない。
「**こういうボードがあるよ**」と教えてあげよう。

1. Arduino IDE の上のメニューから **ファイル** をクリック
2. **基本設定** をえらぶ

> Mac の人は「Arduino IDE」→「Preferences（設定）」だよ。

:::

> 📷 「ファイル → 基本設定」を開くところ（メニューを赤く囲む）

---

# 手順③：ボードのURLを貼りつける

:::

「**追加のボードマネージャのURL**」というらんに、下の文字を貼りつけよう。

1. 下のコードの右上「📋 コピー」を押す
2. らんの中をクリックして、貼りつける（`Ctrl` + `V`）
3. **OK** をクリック

> ⚠ 1文字でもちがうとうまくいかないよ。**手で打たずにコピー**しよう。

:::

```
https://github.com/YuukiUmeta-UIAP/board_manager_files/raw/main/package_uiap.jp_index.json
```

> 📷 基本設定の画面。「追加のボードマネージャのURL」のらんを赤く囲む

---

# 手順④：UIAPduino をインストールする

:::

1. 左のたてならびのアイコンから **ボードマネージャ**（板のマーク）をクリック
2. 検索らんに **`uiap`** と入力する
3. 出てきた **UIAPduino** の **インストール** をクリック
4. 終わるまで待つ（少し時間がかかるよ）

> 「インストール」が「削除」に変わったら成功だよ 🎉

:::

> 📷 ボードマネージャで「uiap」を検索して、インストールボタンを押すところ

---

# 手順⑤：ボードをえらぶ

:::

どのボードを使うのかを、Arduino IDE に教えよう。

1. 上のメニューの **ツール** をクリック
2. **ボード** → **UIAPduino** をえらぶ
3. **Pro Micro CH32V003** をクリック

> 画面の下のほうに `UIAPduino Pro Micro CH32V003` と出ていれば成功！

:::

> 📷 「ツール → ボード → UIAPduino → Pro Micro CH32V003」を選ぶところ

---

# ⚠ シリアルポートは選ばなくていい

:::

ふつうの Arduino の本には「**ポートをえらぶ**」と書いてあるけれど、
**UIAPduino では選ばなくていい**んだ。

- このボードは、パソコンから **COMポートとして見えない**
- 「ポート」のところが**灰色**になっていても、それでOK
- 書き込みは、あとで説明する**べつのやり方**でおこなうよ

> ⚠ 「ポートが見つかりません」と出ても、**こわれていない**よ。安心してね。

:::

> 📷 ツールメニューの「ポート」が選べない（灰色）状態の画面

---

# うまくいかないときは

:::

- **インストールでエラーが出る**
  → URLが正しく貼れているか、もう一度たしかめる
- **Windows で「実行できません」と出る**
  → `Microsoft Visual C++ 再頒布可能パッケージ`（64ビット）を入れると直ることがある
- **ボードマネージャに UIAPduino が出てこない**
  → 基本設定のURLを確認して、Arduino IDE を**いったん閉じて開きなおす**

> こまったら、ひとりでなやまずに**メンターをよんでね**。

> 💪 じゅんびができたら、次はいよいよプログラムを書きこむよ！

:::

> 📷 よくあるエラー画面（実際に出たものをキャプチャして差し替える）
